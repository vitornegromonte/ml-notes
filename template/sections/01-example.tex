\subsection{Equations and Algorithms}

The gradient descent update rule is:

\begin{equation}
    w_i \leftarrow w_i - \eta \frac{\partial E}{\partial w_i}
    \label{eq:gd}
\end{equation}

\begin{algorithm}[h]
\caption{Stochastic Gradient Descent}
\textbf{Input:} Training set $D$, learning rate $\eta$ \\
\textbf{Output:} Trained weights $\mathbf{w}$
\begin{enumerate}
    \item Initialize $\mathbf{w}$ randomly
    \item \textbf{Repeat} until convergence:
    \item \quad Shuffle $D$
    \item \quad \textbf{For} each example $(\mathbf{x}_i, t_i) \in D$:
    \item \qquad $o_i \leftarrow \mathbf{w} \cdot \mathbf{x}_i$
    \item \qquad $w_j \leftarrow w_j + \eta (t_i - o_i) x_{ij}$ for each $j$
\end{enumerate}
\end{algorithm}

\subsection{Theorems}\label{sec:theorems}

When the \texttt{theorems} option is passed to \texttt{tufte-notes}, theorem
environments are available:

\begin{defn}[Perceptron]
A perceptron is a binary classifier that computes
$o(\mathbf{x}) = f(\mathbf{w} \cdot \mathbf{x} + b)$ where $f$ is a step function.
\end{defn}

\begin{thm}[Universal Approximation]
A feedforward network with a single hidden layer containing a finite number of
neurons can approximate any continuous function on a compact subset of $\mathbb{R}^n$.
\end{thm}

\paragraph{Customization}
You can override any color by redefining it after loading the package:
\begin{verbatim}
\usepackage{tufte-notes}
\colorlet{wp-primary}{RoyalBlue}
\end{verbatim}

\paragraph{Output directory}
The Makefile compiles PDFs into \texttt{output/}. To compile manually:
\begin{verbatim}
latexmk -pdf -output-directory=output sections/01-example.tex
